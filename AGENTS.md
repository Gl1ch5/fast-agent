# fa — fast agent

One-file, zero-dependency coding agent for Node 22.18+. Users install the single file `fa.ts`;
the sources live in small modules under `src/`.

## Git workflow

- Work on `main` and push straight to `main` (`git push origin main`). No feature branches, no pull requests.
- The installers and `/update` download `fa.ts` from `main`, so a push to `main` is a release.
- Before every push: `node build.ts` (rebuilds `fa.ts`) and commit `fa.ts` together with the `src/` changes.
  `node build.ts --check` must pass — CI runs it.
- Bump `VERSION` in `src/version.ts` (patch: 0.2.1 → 0.2.2) with every push that changes `src/` — the footer's update notice and the installer summary rely on it.

## Code

- Edit `src/`, never `fa.ts` by hand — it is generated by `build.ts`.
- No dependencies: only `node:` built-ins.
- Imports on one line; local imports use relative paths with the `.ts` extension; type-only imports use `import type` or `type X` inside braces.
- Top-level names must be unique across all of `src/` (the bundle is one scope; the build fails on duplicates).
- Do not call imported functions at module top level except in `main.ts` — modules import each other in cycles.
- Shared mutable state lives in exported objects (`ui`, `agent`, `conv`, `cfg`, `M`), not reassigned `let` exports.

## Layout

```
src/main.ts        entry: print mode (-p, pipes) or the full-screen TUI
src/env.ts         CLI args, ROOT          src/config.ts   ~/.fa/config.json, provider presets
src/prompt.ts      system prompt           src/setup.ts    setup wizard, model selection
src/commands.ts    slash commands          src/update.ts   self-update
src/agent/         agent loop, streaming, shared turn state
src/api/           Anthropic, OpenAI-compatible, /models, HTTP + SSE
src/tools/         write, edit, read, shell, sandbox + undo
src/shell/         shell command → short label, progress parsing
src/ui/            screen/log, render, input, modals, tool cards, welcome, colors
build.ts           bundler: src/ → fa.ts
```

## Checking changes

- `node src/main.ts` runs straight from the sources; `node build.ts` also smoke-tests the bundle.
- The TUI needs a real terminal; for scripted checks use `fa -p "..."` against any OpenAI-compatible server.
