# ⚡ fa — fast agent

**Кодинг-агент в одном файле. Без зависимостей. Без лишних действий.**

`fa.ts` · ~980 строк · 0 зависимостей · Windows / Linux / macOS

---

Современные агенты огромные. На простую просьбу вроде «сделай игру в одном HTML» они
читают полпроекта, строят планы, создают README и тесты и перепроверяют сами себя.

`fa` делает только то, что попросили:

```
› сделай игру змейка в одном index.html
● write index.html  227 lines, 6.2 KB
Создан index.html с игрой «Змейка» (стрелки/WASD, очки, рекорд, пауза).
  19.0s · ↑3.7k ↓2.3k · 2 steps
```

Один вызов инструмента. Ничего лишнего.

## Почему он быстрый

| | |
|---|---|
| 🎯 **Короткий системный промпт** | Чёткие правила: действовать сразу, новый файл писать целиком одним вызовом, ничего не перечитывать, лишних файлов не создавать |
| 📂 **Список файлов уже в контексте** | Модель сразу видит содержимое папки, поэтому не тратит шаг на `ls`. Пустая папка — сразу пишет код |
| 🧰 **Всего 4 инструмента** | `write`, `edit` (сразу несколько правок), `read` (файлы и папки), `shell` |
| ⚡ **Параллельное выполнение** | Независимые вызовы инструментов идут одновременно, вызовы к одному файлу — по очереди |
| 💾 **Кэширование промпта** | Точки кэша Anthropic на системном промпте и последнем сообщении; у OpenAI-совместимых API кэш автоматический |
| ✂️ **Компактные ответы инструментов** | Вывод обрезается, результат записи — одна строка вместо эха файла |
| 🧠 **Регулятор `/think`** | Уровень рассуждений `low` … `max`, или `auto` — по умолчанию у провайдера |
| 🚀 **`/fast`** | Fast mode у Anthropic (Opus, вывод до ~2.5× быстрее) |
| 📡 **Стриминг всего** | Текст, рассуждения, живой счётчик байт, пока модель пишет файл |

## Установка

Нужен **Node.js 22.18+**: он запускает `.ts` напрямую, без сборки.

Одна команда: скачает `fa`, добавит его в PATH и при необходимости поставит Node.js (через winget на Windows или Homebrew на macOS).

**Windows (PowerShell):**

```powershell
irm https://raw.githubusercontent.com/gl1ch5/fast-agent/HEAD/install.ps1 | iex
```

**Linux / macOS:**

```bash
curl -fsSL https://raw.githubusercontent.com/gl1ch5/fast-agent/HEAD/install.sh | sh
```

Без установки: `node fa.ts`. Обновление: запусти ту же команду ещё раз.

## Быстрый старт

```bash
cd my-project
fa                                   # интерактивный режим
fa "добавь тёмную тему"              # сразу выполнит задачу и останется в чате
fa -p "сделай tetris в index.html"   # выполнит и выйдет (для скриптов)
cat log.txt | fa -p "почему падает?" # stdin добавляется к промпту
```

При первом запуске `fa` найдёт ключи в переменных окружения и предложит выбрать модель.

## Провайдеры

Готовые пресеты (ключ берётся из переменной окружения или через `/key`):

| провайдер | переменная |
|---|---|
| `anthropic` | `ANTHROPIC_API_KEY` |
| `openai` | `OPENAI_API_KEY` |
| `openrouter` | `OPENROUTER_API_KEY` |
| `gemini` | `GEMINI_API_KEY` |
| `groq` | `GROQ_API_KEY` |
| `cerebras` | `CEREBRAS_API_KEY` |
| `deepseek` | `DEEPSEEK_API_KEY` |
| `xai` | `XAI_API_KEY` |
| `mistral` | `MISTRAL_API_KEY` |
| `ollama`, `lmstudio` | локальные, без ключа |

**Свой провайдер** — любой OpenAI- или Anthropic-совместимый API:

```
/provider add my http://my-server:8080/v1 sk-xxxx
/provider add proxy https://my-proxy.example.com sk-xxxx anthropic
```

После добавления `fa` сразу загружает список моделей с `/models` и открывает выбор.

## Выбор модели

`/model` загружает модели **со всех настроенных провайдеров параллельно** и открывает поиск:

```
? model › son 5
❯ anthropic/claude-sonnet-5-5 ★
  openrouter/anthropic/claude-sonnet-5
  2/347 · type to search · ↑↓ PgUp PgDn · Enter · Esc
```

- поиск по словам (`son 5`) с запасным нечётким поиском
- недавние модели сверху (★)
- `/model my/some-model` — выбрать сразу, без списка
- `/model !` — обновить список

## Команды

| команда | что делает |
|---|---|
| `/model [поиск]` | выбрать модель |
| `/think [уровень]` | `auto` · `low` · `medium` · `high` · `xhigh` · `max` |
| `/fast` | fast mode у Anthropic |
| `/provider` | список провайдеров · `add <имя> <url> [ключ] [openai\|anthropic]` · `rm <имя>` |
| `/key <провайдер> <ключ>` | сохранить API-ключ |
| `/safe` | спрашивать подтверждение перед каждой shell-командой |
| `/undo` | откатить изменения файлов от последнего запроса |
| `/clear` | новый диалог |
| `/help`, `/exit` | справка, выход |

## Клавиши

| клавиша | действие |
|---|---|
| `Enter` | отправить |
| `Ctrl+J` или `\` + `Enter` | новая строка (вставка многострочного текста тоже работает) |
| `Esc` | остановить агента |
| `Enter` во время работы | поставить сообщение в очередь |
| `↑` `↓` | история |
| `Tab` | дополнить команду |
| `Ctrl+C` ×2 | выход |

## Безопасность: всё в одной папке

- `read` / `write` / `edit` **жёстко заблокированы** внутри рабочей директории (с учётом симлинков). Попытка выйти за её пределы получает отказ.
- `shell` запускается в рабочей директории без stdin, с таймаутом и убийством всего дерева процессов. Для подтверждения каждой команды есть `/safe` или `--safe`.
- `/undo` откатывает все изменения файлов от последнего запроса.

На Windows `shell` — это PowerShell с выводом в UTF-8. Другую оболочку задаёт `FA_SHELL` (например, `FA_SHELL=bash` для Git Bash).

## Конфиг

`~/.fa/config.json` (путь меняется через `FA_HOME`). Создаётся сам, можно править руками:

```json
{
  "provider": "anthropic",
  "model": "claude-opus-5-5",
  "effort": "auto",
  "maxTokens": 32000,
  "providers": {
    "my": { "type": "openai", "url": "http://host:port/v1", "key": "sk-..." },
    "openrouter": { "key": "sk-or-..." }
  }
}
```

Если в папке проекта есть `AGENTS.md` или `CLAUDE.md`, они попадают в системный промпт.

## Опции CLI

```
fa [options] [prompt]
  -p, --print        выполнить и выйти
  -m, --model P/M    провайдер/модель
  -e, --effort LVL   auto | low | medium | high | xhigh | max
  -C, --cwd DIR      рабочая директория
      --safe         подтверждать shell-команды
```
